# Supplementary reproducibility files

These files are regenerated by `gp3ml-paper.Rmd` and retain detailed evidence omitted from the main PDF to satisfy the R Journal 20-page limit.

- `demonstrated-functions.csv`: executed exported functions.
- `locked-analysis-plan.txt`: complete locked plan object.
- `grouped-workflow-objects.txt`: grouped fold and validation objects.
- `decision-policy-objects.txt`: decision-rule and abstention objects.
- `abstention-frontier.csv`: selective-prediction sensitivity grid.
- `optional-dependencies.csv`: runtime availability of declared optional dependencies.
- `session-info.txt`: complete rendering session information.
