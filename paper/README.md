# gp3ml R Journal paper workspace

This directory contains an executable manuscript for:

**gp3ml: Governance-First Predictive Modelling and Validation for Gazepoint Research in R**

## Structure

- `gp3ml-paper.Rmd`: complete R Journal manuscript and executable companion.
- `references.bib`: references cited in the paper.
- `data/evidence.csv`: claim-to-source verification table.
- `R/helpers.R`: manuscript-only helpers and plotting functions.
- `R/case-study.R`: deterministic synthetic analysis.
- `R/render-paper.R`: clean temporary-library R Journal render.
- `R/render-preview.R`: clean temporary-library HTML preview.
- `R/validate-paper.R`: manuscript and package validation.
- `R/audit-package.R`: regenerates package and API facts.
- `tables/`: CSV tables generated by the manuscript.
- `figures/`: optional exported figure files.
- `output/`: rendered journal and preview outputs.
- `supplement/`: supplementary material.
- `motivation-letter/`: R Journal motivation letter.

## Prepare a feature branch

From the repository root:

```r
git <- Sys.which("git")
stopifnot(nzchar(git))
system2(git, c("switch", "-c", "paper/rjournal-manuscript"))
```

## Install manuscript dependencies

```r
source("paper/R/install-dependencies.R")
```

## Render the R Journal formats

```r
system2(
  file.path(R.home("bin"), "Rscript"),
  c(
    "--vanilla",
    "paper/R/render-paper.R",
    normalizePath(".", winslash = "/")
  )
)
```

The script installs the current repository into a temporary library and renders the formats defined by `rjtools::rjournal_article` under `paper/output/`. It does not overwrite the user’s installed `gp3ml` package.

## Static audit without R

The workspace includes a Python-based integrity check for YAML, R chunk labels, citation coverage, portable paths, delimiter balance, evidence-table structure, and an optional Pandoc parse:

```text
python paper/static-audit.py
```

This check does not replace the R runtime validation.

## Validate

```r
system2(
  file.path(R.home("bin"), "Rscript"),
  c(
    "--vanilla",
    "paper/R/validate-paper.R",
    normalizePath(".", winslash = "/")
  )
)
```

The validation report distinguishes passed, failed, and unavailable optional checks. It verifies the temporary 0.3.0 installation, parses all manuscript code, renders the journal formats, runs the package tests and pkgdown check, executes the API contract audit, reruns the leakage-sensitive case study, checks scope language, and confirms that generated changes remain under `paper/`.

## Important interpretation boundary

The case study predicts an explicitly observed synthetic recording-quality review status. It does not infer emotion, stress, cognition, diagnosis, identity, health status, protected attributes, or other hidden sensitive states.
