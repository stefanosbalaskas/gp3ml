# Write an analysis plan

Write an analysis plan

## Usage

``` r
write_gazepoint_analysis_plan(plan, path, format = c("rds", "json", "md"))
```

## Arguments

- plan:

  Analysis plan.

- path:

  Output path.

- format:

  `"rds"`, `"json"`, or `"md"`.

## Value

Normalized output path, invisibly.
