# Describe the schema of a gp3ml object

Describe the schema of a gp3ml object

## Usage

``` r
gp3ml_object_schema(x, recursive = FALSE)
```

## Arguments

- x:

  Object to inspect.

- recursive:

  Whether to include one level of nested named-list components.

## Value

A data frame describing component names, classes, storage types,
lengths, and dimensions.
